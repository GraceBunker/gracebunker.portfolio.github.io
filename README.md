# Grace Bunker — Portfolio

A static, single-page portfolio site.

## Open it
Double-click `index.html`, or run a local server from this folder:

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Work on it with Claude Code
1. Open a terminal in this folder.
2. Run `claude`.
3. Ask for changes in plain English, for example "deploy this to GitHub Pages" or "add a favicon". Claude Code reads `CLAUDE.md` for the design rules.

## Files
- `index.html`: all page content
- `styles.css`: design tokens, components and layout
- `assets/grace-headshot.jpg`: headshot
- `assets/Grace_Bunker_Resume.pdf`: linked from the "Download resume" button. It includes your phone number, so swap it for a version without one if you'd rather not publish that.
